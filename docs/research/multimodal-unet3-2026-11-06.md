# 固定九通道Unet3模型與評估摘要

更新至2026-11-07。隨附模型用於論文概念的簡易復現：取得RD／IR／RA／GI，預測下一個逐時雨量區間。一般使用直接讀取已訓練權重，不需要重新訓練。

| 項目 | 值 |

目前相同檔名的權重已是九通道／101類，設定也已同步。其他架構、模態或類別數必須搭配相符權重。

## 訓練與選模

使用完整歷史資料1045組train、173組val，沿用原颱風切集，檢查每對相差一小時且train／val時間無重疊。完整資料不隨Git提供，與 `database.zip` 小型示範集不同。

模型於2026-11-06在Python3.9、TensorFlow2.9.1環境訓練20輪，batch8、Adam1e-4、seed42，使用本島遮罩及sparse focal loss。此loss保留focal與雨量加權概念，不宣稱與論文binary one-vs-rest逐行相同。以驗證集陸地label-mm RMSE選第13輪，分數4.02438；儲存後重載為4.02439，微小差異來自GPU浮點運算。

GI原始圖與隨附ZIP指紋相同。RA使用來源時刻，目標為下一時刻；原米塔資料中的 `20190931` 檔名保留，只在時間檢查時解析為10月1日並記錄。訓練使用原4700格遮罩，即時RA使用現行縣市界。

## 獨立測試

固定同一份權重，在未用於選模的232組測試上評估，涵蓋蘇力、潭美、蘇迪勒、梅姬；測試時間與train／val無重疊。以下排除海面，只評4700個原本島格點，誤差直接對浮點IDW毫米真值計算。

| 指標 | Unet3 | 持續性預報 |
| --- | ---: | ---: |
| RMSE mm | 4.749353 | 4.754358 |
| MAE mm | 2.051796 | 2.016019 |
| Bias mm，預測−實際 | -0.419977 | -0.031670 |
| ≥1mm POD／Recall | 0.901929 | 0.866570 |
| ≥1mm FAR | 0.173364 | 0.124973 |
| ≥1mm CSI | 0.758462 | 0.771131 |
| ≥1mm F1 | 0.862643 | 0.870778 |

持續性預報沿用上一小時浮點RA。POD=TP/(TP+FN)，FAR=FP/(TP+FP)，CSI=TP/(TP+FP+FN)。RMSE為全部格時誤差平方平均後開根號，與逐張RMSE再平均不同。表中的雨量門檻指標以預測類別對應的整數毫米，對照原始浮點真值判定；另外的101類精確分類指標才直接對原始EWB01標籤計算，不重建目標。

模型RMSE與持續性幾乎持平，MAE、CSI、F1較差；命中較多，也增加誤報。≥20mm命中率約0.45，≥50mm為0，顯示高雨量低估。100以上類別在數值評分以100mm代表，無法表示更高的精確雨量。

## 評估文件是否必要

這份摘要說明模型如何訓練、評分與適用限制，方便研究閱讀者判斷成果。**推論程式不讀取此文件，也不需要本機完整評估報告或訓練輸出。** 公開版本只保留必要摘要；逐小時分數、完整JSON及實跑圖片留在被Git忽略的 `output/` 作進階研究，不是下載後使用的前置條件。

## 使用與限制

```powershell
python -m pip install -r requirement.txt
python run_realtime.py
```

資料發布有延遲，目標時段可能已開始，以輸出實際區間為準。歷史測試有非零雨量分布，但某次即時輸出全0時仍需事後觀測驗證，不能據此認定無雨。現行圖源與歷史影像的解析度、底圖及渲染不同，歷史成績不等同近期天氣精度。

這版固定權重與單一環境，供可執行的多模態示範，不需頻繁重訓。公開圖源格式若改變，資料介接仍可能需維護。[使用說明](../realtime-plugin.md)列出操作、輸出與來源。
