# 現行 RD／IR 與論文研究範圍對齊

更新至2026-11-07。RD、IR與RA共用下述研究網格，並與GI一起輸入九通道、101類Unet3。所有流程使用同一份 `requirement.txt`，其中pyproj 3.6.1負責投影轉換。一般操作見[使用說明](../realtime-plugin.md)。

## 共同研究網格

最終論文印刷第22–25頁描述本島範圍、不同年代RD／IR像素尺寸與128×128輸入，沒有完整地理轉換矩陣。文字中的歷史1024圖crop與實際資料圖的X／Y順序存在差異，因此本次以實際存檔訓練圖上的已知經緯格線校準，並保留論文文字差異，不直接照舊像素數套用現行3600／800產品。

只用176張train RD的median量測120°E／122°E、24°N／22°N格線，得到：

| 項目 | 值 |
| --- | --- |
| 西／東外邊界 | 119.3466666667／122.7600000000°E |
| 南／北外邊界 | 21.8936824807／25.3085641108°N |
| 大小及方向 | 128×128，取像素中心，北向上 |
| 原格線像素中心 | 120E→x24；122E→x99；24N→y48.54890545；22N→y123.51490068 |
| 未參與校準的56張val | 四條線最大差異0.0022／0.0746／0.1713／0.1882像素 |

舊圖只有兩度間隔格線；沒有假造121E、23N、25N作驗證。另以論文嵌圖中的外圍格線檢查，換算至128格點的最大差異約0.42像素。原歷史圖的datum未完整公布，以上小數是推導值，並不代表GPS級精度；現代實作以WGS84座標慣例映射。

RD、IR及RA都使用 `geometry.GridSpec`，共用相同bbox外邊界、格點中心與north-up方向。獨立驗證已確認預測快照與RA重建的 `grid.npz` 座標逐元素相同。

## 現行來源定位

### RD

產品 `O-A0058-003`，3600×3600的8-bit RGB PNG，118–124°E、20.5–26.5°N。實圖格線符合：

```text
x = (longitude - 118) * 600 - 0.5
y = (26.5 - latitude) * 600 - 0.5
```

半像素項不可忽略；整圖外邊界是 -0.5 至3599.5。以NLSC北端、南端、西岸控制點對照實圖海岸線，距離約0.48／0.36／0.23來源像素。[官方XML](https://cwaopendata.s3.ap-northeast-1.amazonaws.com/Observation/O-A0058-003.xml)

### IR

產品 `O-C0042-004`，800×800 JPG。[官方產品說明](https://www.cwa.gov.tw/Data/data_catalog/3-7-2.pdf)提供橫麥卡托與中心121°E／23.7°N，但沒有完整的橢球／比例尺／像素矩陣。XML bbox不能直接當作等經緯圖。

本外掛使用WGS84、k=1、false easting/northing=0的TM座標慣例，依已標示經緯度的16個交點校準像素轉換：

```text
pixel_x =  0.0007823941450716034 * E + 398.9671146696392
pixel_y = -0.000783703003258268  * N + 399.32570925509634
```

棋盤式分為8個校準點、8個保留點；保留點RMS約0.396來源像素，最大0.553來源像素。另以未參與校準的北端、南端、西岸海岸點檢查，距渲染線條約0.47／0.47／0.57來源像素。這些是圖面校正誤差，不是GPS精度，也不是氣象署完整官方geotransform。另檢查10/31 08:30與23:40兩張圖，16個格線交點位置相同；11/1 00:00圖已用於最終推論與疊圖檢查。

相較之下，直接拿XML bbox作等經緯映射，16點RMS約3.85來源像素。圖面4像素邊框是繪圖遮罩，不可把整幅地理extent重新縮成792像素。

## 取樣及產物

- 對共同格點作來源逆投影，以8倍細格點bilinear取樣、再作AREA平均；不只抽單點。
- 來源ROI邊緣的bilinear取樣限制在有效像素中心，避免混入註記；超出覆蓋直接失敗。
- RD保持RGB、IR轉灰階；與RA及GI的正規化、九通道融合交給核心既有融合函式。
- PNG位深／RGB模式、圖種與尺寸會檢查；未知格式不默默套舊定位。
- `alignment.png`：兩來源與疊圖，桃紅線是由232張存檔RA正值聯集重建的4700格本島輪廓；只供目視檢查，沒有畫入模型輸入。
- `alignment.json`／manifest：來源投影、仿射係數、取樣像素範圍及共用網格。
- `georeference_validation.json`／`training_grid_validation.json`：校準點、保留驗證及來源資料。
- `grid.npz`：逐格經緯度。

## 驗證與限制

離線測試涵蓋獨立格線控制點、手算座標漸層、像素半格、方向、RGB／灰階、ROI註記隔離、16-bit格式拒絕與超界拒絕。共同網格已用於實際RD／IR對齊、逐時RA生成及九通道Unet3推論；固定模型與評估結果見[模型摘要](multimodal-unet3-2026-11-06.md)。

校正後新影像對應相同研究範圍，但舊IR是低解析東亞圖裁切放大，現行IR是臺灣TM圖；資訊解析度、底圖與渲染仍不同。舊4700格遮罩和現行海岸約有1–2模型像素差異，未以擬合海岸強行消除此差異，因此仍不宣稱逐像素重現原RA rasterizer或提升模型預報準確度。
